# Сохранённая лента Codex

Дополнение для проверенного Hermes 0.23.1+2062 сохраняет сведения для интерфейса в штатном `display_metadata`. Реальные аргументы, результаты JSON и запросы модели не меняются.

Эталон - действующий Codex Desktop 26.1117.3838.0. Имена берутся из сохранённых `task_name`/`agent_path`, аватар из подтверждённого ID дочернего чата. Исторические уведомления связаны по ID строки и делегирования. Обрезанное поручение не используется как имя или ключ связи.

`timing.py` фиксирует границу принятого хода, начало действительно выведенного итогового ответа и его завершение. `file_capture.py` сохраняет проверенную разницу до/после нового локального `write_file` под штатной блокировкой файла. Служебный снимок передаётся отдельным атрибутом строки и переносится в display sidecar до сохранения; JSON для модели остаётся прежним. Размер захвата ограничен 1 MiB, объём сравнения - 4 млн пар строк. Неподтверждённые, удалённые и слишком большие снимки не подменяются содержимым запроса.

`manifest.json` закрепляет точные исходные и итоговые SHA-256. Установка принимает только проверенные байты. Дополнение MCP устанавливается перед этим дополнением; его повторная установка сохраняет точно известные новые поля контракта.

```powershell
python -B scripts/stage-hermes-timeline.py
python -B scripts/install-hermes-timeline.py --install
```

Сначала проверяется кандидат в отдельном профиле. Установщик сохраняет копии для отката, публикует дополнения перед использующими их файлами и проверяет результат. Перезапуск шлюза выполняется штатно после подтверждения отсутствия активной работы.

Серверная часть плагина читает историю в своём профиле, выдаёт только разрешённые метаданные и сохранённые правки выбранного хода. Отмена и повторное применение используют эти правки, проверяют версию снимка и конфликт, сохраняют состояние операции. Неизвестный исход не запускается повторно автоматически. Текущие изменения родительского Git не выдаются за историю ребёнка.

Старое отсутствующее имя или время начала ответа не восстанавливаются из пересказа поручения и времени завершения. Старые патчи без доказанной локальной папки доступны для чтения. Отмена требует доказанного контекста исходного вызова. Native восстановление переписки не используется как отмена файлов.
