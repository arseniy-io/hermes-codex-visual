# Явное имя субагента Hermes

Имя задаёт ведущий агент в `tasks[].task_name`, например `method_review`. Полное поручение остаётся в `goal`. Сервер создаёт путь `/root/method_review`, а у вложенного агента продолжает сохранённый путь родителя. Интерфейс берёт последний сегмент пути и применяет подтверждённое форматирование Codex. Сервер не переводит имя и не извлекает его из поручения.

Новая схема инструмента требует `task_name` при создании задачи, в том числе при совместной доставке через `group`. Получатель сохраняет совместимость со старыми вызовами без имени. Старый одиночный вызов с `goal` принимает также `task_name` на верхнем уровне. Задачи без имени сохраняют прежний состав данных. Имя и путь передаются отдельными полями `task_name` и `agent_path` в событиях, текущем списке и результатах ребёнка. У сохранённого фонового вызова `task_names[]` и `agent_paths[]` индексируются исходным `task_index`, как `goals[]`; в смешанном вызове у неназванной задачи стоит `null`. Сохранённый `model_config` ребёнка содержит `_task_name` и `_agent_path` для продолжения после перезапуска. Восстановление использует тот же собственный store родителя, включая `AsyncSessionDB` и `ChildSessionStore`, а не глобальную базу другого профиля.

`scripts/stage-hermes-agent-names.py` проверяет SHA-256 исходных файлов и создаёт кандидат только в `.local/hermes-agent-names-check/candidate`. Этот сценарий не устанавливает файлы и не затрагивает отдельную правку очереди `gateway/session_authority.py`. До установки должны пройти проверки `scripts/check-hermes-agent-names.py` с Python проверенной сборки Hermes, а родительский исполнитель должен сверить контракт с подключением интерфейса.

Источники фактического контракта Hermes: `tools/delegate_tool.py`, `tools/delegate_tool_progress.py`, `tools/delegate_tool_child_run.py`, `tools/delegate_tool_dispatch.py`, `tools/delegate_tool_registry.py`, `tools/async_delegation.py`, `tools/async_delegation_worker.py`, `gateway/session_worker_delegation.py`, `tui_gateway/tool_progress.py`, `gateway/session_ancillary.py`. Существующая схема не имела отдельного имени; `group` отвечает за совместную доставку результата и остаётся самостоятельным полем.
