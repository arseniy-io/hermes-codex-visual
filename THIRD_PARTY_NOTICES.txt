Shared workspace artwork
========================

source/visual-assets.json contains the SVG set preserved from the owner's
existing local Codex-style theme: 138 interface icons, 28 pairs of subagent
badges, and 4 installer icons. It was originally collected from Codex Desktop
for visual compatibility. The owner approved using this same set in the public
and local builds on 19 November 2026.

This set is separate from Tabler and is not covered by the Tabler MIT license
above or by the repository's source-code MIT license. No separate license grant
for the shared artwork is recorded here; rights remain with its respective
owners. Owner approval records the project publication decision, not a license
grant from a third-party rights holder.

GitHub activity icon addition
----------------------------

The activityGithub icon in source/visual-assets.json is an additional Codex
Desktop compatibility resource, requested by the owner on 20 November 2026.
Source: Codex Desktop 26.1111.2228.0, webview/assets/async/956370.aff5cce818.js,
module mS6z (used by hPoZ for GitHub). The original 138 interface icons remain
unchanged. This addition has the same third-party rights status described
above and is not a Tabler icon.

Exploration activity icon additions
----------------------------------

The activitySkill and activityList names are used only for conversation
activity. activitySkill reuses the preserved wrench SVG (wrench-light-16).
activityList uses Codex Desktop 26.1111.2228.0 folder-light-16, module RkfJ
in webview/assets/async/98815.42a3b2f915.js. The active consumer is dI55.J:
readSkill.original = bVeK.FJG -> B6lB and listFiles.original = bVeK.efV
-> RkfJ. The original 138 icons remain unchanged, including the separate
skill-library cube and project-folder icon. These compatibility resources
have the same third-party rights status described above.

The archiveToast and archiveToastClose icons are the archive-light-16 and
xmark-md-light-16 resources from Codex Desktop 26.1117.4957.0,
webview/assets/async/972521.8b15fff44b.js, modules tuXZ and i1uX. The
archiveToastPending graphic follows its FyDI loading indicator. Their consumer
is H4Rl in 601050.adaf07012c.js. The archiveToastRestored icon is
circle-checkmark-light-16 from module k1yo in 364313.d749d31da5.js.
These resources have the same third-party rights status described above.

The stop and resume composer icons in source/turn-control.js are from Codex
Desktop 26.1117.4957.0: aJad in webview/assets/async/103760.8bc82953e4.js
and EVaN in webview/assets/async/839700.c1fe868f96.js. The latter file uses
both in its composer submit button. They have the same third-party rights
status described above and are not Tabler icons.

Hermes transcript compatibility
==============================

The transcript visibility rules in source/agent-transcript-visibility.js and
the Hermes source adaptations in source/hermes-tool-display/core.patch are
derived from the corresponding Hermes Agent and Desktop components.
