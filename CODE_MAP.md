`Focus` - имя ветки в [verification/sandbox.spec.mjs](verification/sandbox.spec.mjs). Обёртка [run-local.ps1](verification/run-local.ps1) получает `-Focus`, `-Plugin`, `-EvidenceVersion`. Она запускает отдельный профиль с тестовыми данными. `npm run check` подтверждает воспроизводимость сборки и синтаксис, но не вид интерфейса. Наличие сценария в этой карте не означает, что он прошёл на новом кандидате.

Для read-only диагностики тестовой среды выполни `python -B scripts/runtime_diagnostic.py --project . --hermes-root (Join-Path $env:LOCALAPPDATA 'hermes')` в PowerShell с Python 3.11 или новее. Код 1 означает обнаруженное расхождение в проверенных файлах, 2 - неизвестное состояние; код 0 не подтверждает совместимость или загрузку в gateway. Команда распознаёт только заранее изученные версии исходников и ничего не устанавливает. Проверки команды: `python -B verification/test_runtime_diagnostic.py`; не запускай их одновременно с подготовкой preview, поскольку они временно создают свои каталоги в `verification`.

По прямому конкретному исключению владельца, например «убрать секунды», меняй только названное свойство. Повторное исследование Codex по этому исключённому свойству не нужно. При поручении повторить Codex начни с реестра и проверь активный компонент, данные и состояние выбранной версии; скриншот сам по себе не доказывает весь механизм.

Если элемента нет в карте, ищи его подпись или `data-slot` в `source/` через `rg`, затем регистрацию модуля в `source/plugin.js`. Не редактируй корневой сгенерированный `plugin.js`. После нового устойчивого маршрута обновляй только соответствующую строку карты. Текущую версию бери из `package.json`, а реально загруженную - из записи активации рабочего Hermes при разрешённой задаче установки.
